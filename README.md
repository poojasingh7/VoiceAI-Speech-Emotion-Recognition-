# 🎙️ VoiceAI — Speech Emotion Recognition

## 📌 Overview
VoiceAI is a multimodal Speech Emotion Recognition system that analyzes speech using Machine Learning, Deep Learning, speech transcription, sentiment analysis, and Explainable AI (XAI).

## ✨ Features
- 🎤 Live microphone recording and audio file upload
- 🧠 Speech emotion classification
- 📊 Acoustic feature and vocal prosody analysis
- 📝 Speech-to-text transcription
- 😊 Sentiment analysis
- 🤖 Machine learning and deep learning model comparison
- 📈 Emotion confidence scores and visualizations
- 🔍 Explainable AI insights
- 🗄️ Database integration and user authentication

## 🎭 Supported Emotions
- Neutral
- Calm
- Happy
- Sad
- Angry
- Fearful
- Disgust
- Surprised

## 🛠️ Technology Stack

**Frontend:** React, Vite, Tailwind CSS, Recharts

**Backend:** Python, FastAPI, Uvicorn

**AI/ML:** Scikit-learn, PyTorch, Librosa, Whisper, NLTK VADER

**Database:** MySQL / SQLite, SQLAlchemy

**Security:** JWT authentication and password hashing

## 🚀 Getting Started

### Prerequisites
- Python 3.11
- Node.js and npm, if required by the frontend
- MySQL 8.0, if using MySQL

### Run the Application
1. Clone or download this repository.
2. Install the required backend dependencies.
3. Configure your environment variables and database.
4. Install frontend dependencies if required.
5. Start the application using the project's configured startup command.

The project documentation specifies `python run_app.py` as the startup command. Verify it against the current code.

### API Documentation
When the backend is running, the documented API URL is:

`http://localhost:8000/docs`

## 🔒 Privacy
Do not upload passwords, secret keys, private recordings, or personal database information to a public repository.

## ⚠️ Disclaimer
Emotion predictions are estimates based on speech signals and language. They should not be treated as definitive judgments of a person's emotional state.
